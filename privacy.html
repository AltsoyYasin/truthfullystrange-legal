Privacy Policy

Truthfully Strange Publisher · Last updated: 21 November 2026

1. Summary

Truthfully Strange Publisher is a personal tool that posts the channel's own videos to the channel's own TikTok account. It does not collect data about viewers or any other TikTok users.

2. Data the app uses

  • TikTok account authorisation: an access token and refresh token issued by TikTok when the channel owner signs in. They are stored only on the owner's own computer and used only to upload videos.
  • Basic account info (user.info.basic): the account's display name and ID, used to confirm the correct account is connected.
  • Videos and captions that the channel created and chose to publish.

3. What the app does not do

It does not read, store or analyse other users' profiles, videos, comments, messages or contacts. It does not sell or share any data with third parties, and it does not use advertising or tracking.

4. Storage and security

Tokens are kept in a local file on the owner's computer, are never published, and are not stored on any server operated by the app.

5. Deleting data / revoking access

Access can be revoked at any time in the TikTok app (Settings and privacy → Security and permissions → Apps and services) — this immediately invalidates the tokens. The local token file can then be deleted.

6. Children

The app is not directed at children and is used only by the channel owner.
